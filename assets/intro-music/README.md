# Opening film soundtracks

- `gta-4-intro.mp3`: the GTA IV intro, used **temporarily for testing** (currently in the film). Rockstar's copyrighted music: switch back before students see it.
- `eat-better-music-bed.mp3`: the soft music bed generated by `scripts/intro/build-film.mjs` (the original soundtrack).

Swap the film's soundtrack in seconds (both film sizes, from the clean original video):

```
node scripts/intro/swap-music.mjs assets/intro-music/gta-4-intro.mp3 1.5
node scripts/intro/swap-music.mjs assets/intro-music/eat-better-music-bed.mp3
```
